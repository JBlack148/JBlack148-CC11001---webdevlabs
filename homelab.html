Homelab

← Back to Projects

I run multiple services at home on my servers so that I can understand networking in a hands-on way.

Services include:

  • Proxmox (VM's and containers)
  • Open media vault (File storage)
  • Jellyfin (Media server)
  • Tailscale (Remote access)

Layout:

I currently run two HP EliteDesk Mini PCs mounted in a 10” server rack, connected via a network switch.

The primary machine hosts a virtualised NAS using OpenMediaVault, configured with 1TB RAID 1 (mirrored) storage and providing both NFS and SMB shares. It also runs a virtualised k3s control plane.

The second machine acts as a worker node host, running three virtualised k3s worker nodes. I set this up to gain hands-on experience with managing a multi-node Kubernetes cluster.

Within the k3s cluster, I have deployed services including Jellyfin and Tailscale.

Expansion:

I plan to expand the rack with additional SFF machines. One will be dedicated as a router, positioned above the switch and running OPNsense, as I’d like to gain hands-on experience with network routing.

I also intend to add more machines to increase the number of k3s nodes, with the goal of transitioning the worker nodes from virtualised instances to bare-metal deployments.
