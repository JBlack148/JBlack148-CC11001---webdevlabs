Maze Generator / Solver

A simple maze generator that randomly generates mazes of a size chosen. This was written in Python as my project for Advanced Higher Computer Science.

Algorithm & Features:

  • Iterative backtracking algorithm for maze generation
  • A* search algorithm for maze solving
  • Custom stack implementation using linked list
  • Turtle graphics for visualization

Technologies Used:

  • Python programming language
  • Turtle library for graphics
  • Random library for generation
  • Heapq library for A* search

Database Integration:

This project was linked to a database, so that the mazes could be stored and retrieved. The mazes were converted to a binary string and stored in a blob in the database, the reverse conversion is performed when retrieving a saved maze. This was done using SQL and PHP.
