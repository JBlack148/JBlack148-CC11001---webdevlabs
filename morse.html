Morse Code Translator

← Back to Projects

This is a morse code decoder running on a Raspberry Pi. You can tap morse code on the button and it gets decoded into letters and then published on an MQTT server. The morse code is then taken from the MQTT server and displayed on an LED matrix.

How it Works:

  • Tap morse code on a physical button
  • Decode morse code into letters
  • Publish decoded letters to MQTT server
  • Display letters on LED matrix

Hardware & Technologies:

  • Raspberry Pi microcontroller
  • RPi.GPIO library for button input
  • LED matrix display
  • MQTT protocol for communication
  • HiveMQ broker

Technical Challenges:

There was a lot of trial and error in this project as there was no available documentation on our specific dot matrix display, so I had to test each pin to find out which was which. I also made custom 2D arrays to be displayed on the LED matrix for each character.

Skills Learned:

  • Cross-ghosting on LED matrices and how to mitigate it
  • Hardware interfacing with GPIO
  • MQTT communication protocols
  • Embedded systems development
